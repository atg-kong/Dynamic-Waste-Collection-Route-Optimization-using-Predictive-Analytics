  🚀 LAUNCH DASHBOARD IN VS CODE - SUPER SIMPLE! (30 SECONDS)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Open VS Code
   • Open Visual Studio Code application
   • File → Open Folder → Select this project folder

STEP 2: Open Terminal
   • Press: Ctrl + ` (backtick key, above Tab)
   • Or: View → Terminal
   • Or: Terminal → New Terminal

STEP 3: Launch Dashboard
   Type in terminal:
   
   streamlit run app.py

   Then press Enter

STEP 4: Open in Browser
   • Look for this message in terminal:
     
     Local URL: http://localhost:8501
   
   • Ctrl+Click on the URL (it's clickable!)
   • Or manually open browser and go to: http://localhost:8501

STEP 5: Present!
   • Dashboard opens automatically
   • Press F11 for full screen
   • Start your presentation! 🎉

═══════════════════════════════════════════════════════════════════════════════
  ⚠️ COMMON ISSUES & QUICK FIXES
═══════════════════════════════════════════════════════════════════════════════

❌ ERROR: "streamlit: command not found"
   FIX: pip install streamlit

❌ ERROR: "No module named 'pandas'"
   FIX: pip install -r requirements.txt

❌ ERROR: "Port 8501 already in use"
   FIX: streamlit run app.py --server.port 8502

❌ Dashboard won't load
   FIX: 
   1. Close browser
   2. In terminal, press Ctrl+C to stop
   3. Run again: streamlit run app.py
